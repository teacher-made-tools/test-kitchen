# Test Kitchen

A test kitchen for classroom ideas: free interactive activities made by teachers, for teachers.

Live site: https://teacher-made-tools.github.io/test-kitchen/

## What's here
- `index.html` home page
- `quick-breads.html` activity page
- `demo/` live demos (preview mode, nothing is saved)
- `downloads/` the Index.html and Code.gs files teachers copy to make their own version

To preview locally, open `index.html` in a browser.
