Which Move Next? Solving Equations

BETA Math Step by step 4 activities, 14 problems Saves to Google Sheets
This is a BETA activity. It is still being worked on, so problems, wording, and saved results may change. Try it with a small group first, and expect updates.

Students read a short box, then choose the best next move to solve an equation. Their work builds down the page like a notebook, and every wrong choice explains why. They practice two-step equations, variables on both sides, and distributing. Each solved problem saves to your Sheet.

Two-Step Equations
3x + 5 = 20
◂ Subtract 5 from both sides
− 5     − 5
3x = 15
Step 2: which move comes next?
Divide both sides by 3 ✗ Multiply both sides by 3 Subtract 3 from both sides
x is already multiplied by that number. To undo multiplying, divide.

Set up your own copy

About five minutes. You need a Google account and a Google Sheet.

  1. 1

    Download the two files

    Index.html Code.gs

    If a file opens as a page in your browser, press Ctrl+U to see the code. Select it all and copy.

  2. 2

    Make a new Google Sheet

    Name it anything you like. This is where student results will land.

  3. 3

    Paste the files into Apps Script

    In the Sheet, choose Extensions, then Apps Script. Paste Code.gs into the Code.gs file. Add an HTML file named exactly Index and paste Index.html into it.

  4. 4

    Publish it as a web app

    Choose Deploy, then New deployment, then Web app. Set Execute as to Me. Set Who has access to your school domain. Approve the permissions when asked.

  5. 5

    Share the link with students

    Copy the web app link and post it in your class. Students type their name once and results appear in a Results tab in your Sheet.
